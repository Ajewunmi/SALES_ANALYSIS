# Sales Analysis Dashboard

A data-driven **Sales Analysis Dashboard** built using **Excel, Power Query, and Power BI** to provide actionable insights into sales performance, customer behavior, and profitability.

---

## Project Overview

This project delivers an interactive dashboard designed to help stakeholders:

- Monitor key financial metrics
- Identify top-performing brands
- Analyze revenue distribution
- Track customer trends over time
- Evaluate profit patterns across segments

---

## Tools & Technologies

- **Microsoft Excel** – Data storage and initial structuring  
- **Power Query** – Data cleaning, transformation, and modeling  
- **Power BI** – Data visualization and dashboard creation

## Key Features

### KPI Summary
- **Total Cost:** 2M  
- **Total Revenue:** 3M  
- **Customer Count:** 5,200  
- **Total Profit:** 932K  

### Visual Insights

- **Profit by Brand**
  - Top brands include: Apple, Lenovo, Samsung, HP, Asus, Dell
  - Apple shows the highest profit (~197K)

- **Revenue by Product Color**
  - Distribution across White, Gray, and Black
  - White contributes the highest (~39%)

- **Revenue by Year**
  - Latest recorded year: **2023**
  - Total revenue: **~3.1M**

- **Profit by Income Level**
  - Medium income group generates the highest profit (~347K)
  - Decline observed toward low-income segment

- **Customer Trends**
  - Monthly variation in customer count (~1,719 – 1,741)
  - Slight fluctuations but relatively stable pattern

### Interactive Filters
- Category (Accessories, Electronics)
- Region (East, North)

---

## Recommendations

Based on the dashboard insights:

- **Focus on high-performing brands** like Apple to maximize profit
- **Target medium-income customers**, as they generate the most profit
- **Optimize product mix** by prioritizing high-revenue colors (e.g., White)
- **Monitor monthly customer trends** to identify seasonal demand patterns
- **Expand region/category analysis** for deeper market penetration insights
